# ad-kerberos-lab
Built and assessed a small Azure-hosted Active Directory environment to understand Kerberos authentication vulnerabilities: AS-REP Roasting and Kerberoasting. This project combines guided learning from TryHackMe's Attacktive Directory room with an independently built Windows Server Lab (Azure) to demonstrate the attacks and explain why they work.
